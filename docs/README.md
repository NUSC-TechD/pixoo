# Operations documentation

- [Prerequisites](prerequisites.md) — flash Raspberry Pi OS, create the PixooLocal hotspot, and intercept Divoom DNS.
- [Deployment](deployment.md) — install, configure, deploy, update, and verify the server on a Raspberry Pi.
- [Debugging](debugging.md) — diagnose hotspot, DHCP, DNS, MQTT, HTTP, Docker, display, and power problems.

These runbooks assume the current NUSC deployment defaults:

- Raspberry Pi hotspot: `PixooLocal`
- Raspberry Pi hotspot address: `10.42.0.1`
- Example Pixoo address: `10.42.0.8`
- Installation directory: `~/nusc-pixoo`

Replace those values where your deployment differs.
